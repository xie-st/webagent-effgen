# 完整 EffGen 单智能体 Roadmap

2026-10-30。负责人：Codex。状态：方案交付，尚未实施。用户本轮要求：保留一个完整 EffGen 智能体，通过工具、提示词、skill 和记忆改善上下文；本轮只写精简路线图。

## 开发方向

**让 EffGen 拥有完整的观察—思考—工具执行—反馈循环，并持续负责规划、核验与恢复。外围代码负责连接环境、保存事实、检查协议和记录日志。**

当前 `policy.py` 每次用无工具的 EffGen 生成一个决策，Runtime 再组织核验与恢复。原方案试图通过显式分工提高可靠性，但任务判断分散，新增规则需要跨模块协调。新方案把这些语义判断收回同一个 Agent；保留已有 SDK、模型网关、动作格式校验和日志，把任务专用核验规则移出强制控制流程，按需转成工具或 skill。

选择：先建立完整单 Agent 基线，再逐项增强。单 Agent 可以自己调整计划、核验和修复；“完整”指决策与执行历史连续，不要求把所有材料永久塞进上下文。

```text
自然语言任务 → 一个 EffGen Agent（同一任务持续运行）
                   ├─ 网页工具：读取页面、执行动作、获取新观察
                   ├─ 任务工具：读写进度、查询历史证据
                   └─ skill：按需读取短流程

模型调用 → 官方统一模型适配器
网页工具 → 官方单动作桥接 / 本地浏览器
每次模型调用前 → 组装必要上下文
```

## 实施顺序

| 阶段 | 只完成这件事 | 交付与验收 |
| --- | --- | --- |
| 1. 完整 Agent 基线 | 固定 EffGen 版本，启用单 Agent 工具循环；先用本地浏览器跑通，再接官方接口 | 同一任务内 Agent 连续完成观察、多个动作、结果核验与结束；保存真实模型与网页轨迹 |
| 2. 精简工具与提示词 | 首版只提供网页读取/行动、任务状态读写、历史证据查询；系统提示明确目标约束、完成依据和异常处理 | 工具返回当前观察版本及真实结果；元素编号当轮有效；未知写入结果先查询；结束时有任务要求对应的网页证据 |
| 3. 任务记忆与上下文 | 原始轨迹外存；上下文常驻原任务、结构化进度、当前页面与近期必要交互 | 长任务压缩后仍保留约束、已确认事实、未确认动作与下一步；需要旧细节时能按引用取回 |
| 4. 少量 skill | 从实际失败和重复流程中提炼短技能，先做最常用的两三个；只注入索引，按需加载正文 | 每份写清适用条件、参数、操作要点、成功依据和退出条件；元素编号实时绑定；同一 Agent 可随时调整或退出技能 |
| 5. 按证据迭代 | 固定一组任务，每轮只改一个问题对应的工具、提示、skill 或记忆策略 | 保存通过率、总耗时、模型调用量及可得 token；先保通过，再保留有收益的改动 |
| 6. 真实网站并行与交付 | 同一 Agent 调用多 Tab 批量读取工具；工具层负责并发 I/O、限流和共享写入协调；接入人工接管 | 同任务对照串行/并行耗时；接管后重新观察并续做；完成官方用例、真实演示和3–5页报告 |

## 第一个工程关口：完整循环接官方单步协议

本地浏览器可直接执行工具并返回结果。官方接口则必须跨 `step` 等待：Agent 发出网页动作 → 桥接器把它作为本轮唯一动作返回 → 下一次 `step` 收到新观察 → 将观察作为该工具的结果交还原 Agent → 原循环继续。

先做一个只验证这条链路的小原型。若需独立执行线程维持 `Agent.run()`，模型请求也须经桥接交回当前有效 SDK 回调执行，不能让后台线程直接调用官方模型。`reset`、超时、取消和关闭时终止旧运行、清空等待，防止跨任务串线。具体暂停方式以所固定版本的实际接口验证为准。

**这一关通过后再迁移现有模块，避免重新把 Agent 缩成每步生成一次 JSON 的 policy。**

## 上下文的最小设计

- **任务事实**：原始目标、约束、已确认进度及来源、待确认动作、当前障碍。事实和计划分别存放；模型摘要不能直接升级为成功证据。
- **当前工作上下文**：系统提示、任务事实、当前页面、近期必要交互、当前相关 skill。先去掉重复历史，再优化长页面；裁剪后可展开完整 AX。
- **可检索轨迹**：完整观察、动作、结果与时间外存，按步骤或对象读取。历史元素编号只作记录，执行前重新定位。
- **跨任务复用**：初期只维护用户可编辑的版本化 skill；任务状态每项清空。后续有证据再决定是否需要独立长期记忆库。

压缩在接近上下文预算时触发，保留原任务、未决事项和证据引用；记录压缩自身耗时与调用，避免省输入却增加总开销。
