# 模型候选核查

核查日期：2026-10-28。范围：当前对话、根目录协作及研究评估指导、指定赛题材料与公开一手来源。服务于“先跑通任务”的模型筛选，不涉及训练或模型部署。

## 筛选结论

模型侧筛出 **BU-30B-A3B-Preview 配 Browser Use**（训练与浏览器框架直接匹配）、**Qwen3.8-27B 配网页工具**（先进通用规划、视觉与工具能力）、**MolmoWeb-8B 配官方执行器**（规模小、网页端到端完整开放），以及截图与长流程候选 **Holo4-27B**。结合另行核查的Fara1.5，综合短稿将首轮收敛到BU、Qwen及Fara1.5，MolmoWeb和Holo4保留备选；Fara1.5依据见本轮工具与证据核查。

这是按任务匹配与可获得性作出的筛选判断，未在比赛环境运行。公开分数只用于确认候选具备相应能力，不能代替本赛题通过率。

## 重点候选：能力、获得方式与评测口径

### BU-30B-A3B-Preview

官方模型卡明确以 Qwen3-VL-30B-A3B-Instruct 为底座，专门训练适配 Browser Use 的 DOM 理解及视觉推理；64K 上下文。提供 vLLM 自托管、OpenAI兼容端点接入 Browser Use 的示例。**直接匹配“先跑通任务”的整套基线**；本次所读模型卡没有可用于与其他候选同协议排名的成绩表。模型卡有BU Cloud调用示例，但[当前仓库模型文档](https://github.com/browser-use/browser-use/blob/main/skills/open-source/references/models.md)明确Cloud不路由此检查点；本轮采用自托管接入，不认定该商业路由可用。商业服务默认模型不能替代此指定检查点的参数证明。

来源：[官方模型卡](https://huggingface.co/browser-use/bu-30b-a3b-preview)。

### Qwen3.8-27B

最新官方27B通用视觉模型，Apache-2.0权重，支持 vLLM/SGLang、结构化工具与可调推理。官方卡报告 OSWorld-Verified 84.3、WebArena-Verified 64.8；后者明确采用 **OSWorld scaffold 与 WebArena-Verified 官方 grader**。其价值是同一模型承接规划、DOM理解与截图观察；接入 Browser Use 后仍需验证其工具协议和执行表现，不能把官方 scaffold 成绩移植给 Browser Use。

来源：[官方模型卡，含协议说明与部署](https://huggingface.co/Qwen/Qwen3.8-27B)。

### MolmoWeb-8B / 4B

Ai2于2026年3月发布截图驱动网页模型，4月补齐训练、评测与客户端代码。8B权重实际8.66B，Apache-2.0。官方仓库包含浏览器执行器、模型服务及批量评测；支持点击、输入、页面导航和标签切换，适合作为小规模完整网页基线。

论文表4中8B的 WebVoyager / Online-Mind2Web 为78.2 / 35.3；100步，3–5次均值，使用各基准VLM judge，WebVoyager采用剔除不可执行任务的任务集，Browserbase环境。94.7 / 60.5是pass@4，不是单次通过率。正文及必要附录已核查；“开放数据与专门训练可形成有效小网页模型”的证据支撑8/10。

来源：[模型卡](https://huggingface.co/allenai/MolmoWeb-8B)、[官方仓库](https://github.com/allenai/molmoweb)、[论文第3–4节及附录](https://arxiv.org/html/2604.08516v1)、[官方发布与代码更新](https://allenai.org/blog/molmoweb)。

### Holo4-27B / 35B-A3B

2026年9月开放，27B来自Qwen3.8架构、35B-A3B来自Qwen3.6架构，配套 `hai-agents` harness；可发出截图GUI操作、代码及工具调用。27B权重为CC-BY-NC-4.0，35B-A3B为Apache-2.0；官方同时提供付费模型API。

官方报告OSWorld 85.2 / 80.8，Agentic Task Factory的web子集80.2 / 70.8。后者是自建未用于训练的测试集、混合域内外任务，不能与WebArena横比。官方提供公开基准的完整轨迹；OSWorld等结果为自有harness下2–4次均值。**27B值得作截图与长流程候选**；35B-A3B先核赛方MoE放宽口径。应用时只开放赛题允许的网页工具。

来源：[官方模型规格与API](https://hcompany.ai/research/models)、[官方发布、评测脚注与轨迹](https://hcompany.ai/newsroom/holo4)、[35B模型卡](https://huggingface.co/Hcompany/Holo4-35B-A3B)、[27B模型卡](https://huggingface.co/Hcompany/Holo4-27B)。
