# 华为 2026 Hackathon — WebAgent

种子 Agent 已选定为 **EffGen**。固定开发入口为 `02_代码/01_harness/`，统一测试结果入口为 `01_文本/05_测试结果/`。

## 启动与检查

在项目根目录运行，Python 3.11 及以上：

```powershell
python webagent.py check
python webagent.py test
python webagent.py connect
```

`check` 核对默认版本、官方 SDK 指纹、Agent 导入与连接配置；`test` 运行本地协议检查；`connect` 连接赛方，随后在网页发起评测。任意目录均可用 `python "项目绝对路径/webagent.py" check` 调用。

指定旧版本：`python webagent.py connect --version v1`。默认版本只在 [webagent.json](webagent.json) 的 `default_harness` 中切换。

当前 `v1` 基于官方 baseline 修正单 Tab 限制，是可检查的参照版本。EffGen 历史运行由用户确认，具体安装与代码来源仍在定位；本轮没有将历史成绩绑定到 v1，也没有新增 EffGen 适配实现。

## 更新与回溯

harness 继续按 `v1/`、`v2/` 等独立存放；新版本从上一版复制后修改，附版本 README；保留旧版本及名称，默认版本通过配置切换。

每次 `connect` 都创建新的结果目录，并从该次保存的 harness/SDK 快照启动。`run.json` 记录版本、Git 提交、工作区状态和文件 SHA-256；以后修改源目录不影响已经启动的运行。目录唯一标识采用 UTC 时间，运行记录保留 ISO 时间。

官方分数从平台导出后放入该次 `raw/`，把平台批次及任务编号、指标与结论写入 `run.json` 和 `result.md`；客户端退出状态与官方成绩分别记录。连接会话可以对应多个平台批次，记录时逐项列出。

Git 同步源码、版本目录、官方 SDK、文档、成绩摘要和运行元数据。连接令牌、虚拟环境、缓存、原始页面日志与运行快照保留本机并被忽略；归档中含凭据的历史安装脚本也被忽略。
