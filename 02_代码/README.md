# 代码

架构与路线图见[开发方案](../01_文本/06_开发框架/开发方案.md)。Agent 功能在当前版本内实现；网页练习与工程工具分别在下列目录维护。

| 目录 | 用途 |
|---|---|
| [01_harness](01_harness/README.md) | 当前开发代码与已保存的大版本 |
| [02_本地测试环境](02_本地测试环境/README.md) | 练习网页、浏览器运行器和环境检查 |
| [03_工程工具](03_工程工具/README.md) | 检查启动入口与版本复制 |

官方 SDK 保存在每个版本的 `sdk/` 中，保留原件。新增模块同时补上相应验证和运行说明；进度回填开发方案。
