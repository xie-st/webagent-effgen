# M3 浏览器与调度

在现有M2上增加浏览器适配、接管/恢复、站点限流、DAG调度和草稿保护。官方MyAgent入口继续使用单Tab协议；M3浏览器是独立运行入口。

## 运行

安装现有Agent依赖，再安装`requirements-browser.txt`及Playwright浏览器（本机测试用已安装的Edge）。准备用户授权的模型连接文件和任务计划：

```powershell
python webagent.py m3 --plan .local/tasks.json --model-env .local/model.env --workers 3 --channel msedge --headed --out 01_文本/05_测试结果/local/唯一运行名
```

默认工厂为`web_agent.http_model:make_runtime`，读取本机env中的模型名、BASE_URL和密钥（字段模板见`.env.example`），调用OpenAI兼容HTTP接口，再通过既有SdkModelPort/EffGen接入Runtime。所有模型调用默认串行，浏览器读取可并发。也可用`--runtime-factory my_model:make`替换；工厂`make(spec, context)`须返回新的Runtime。比赛连接的job绑定模型不自动成为本机独立服务。文件放`.local`，不得提交凭据或登录状态。当前普通Edge既有标签页不在此入口的接管能力内，加载storage-state不等于连接用户现成标签页。

计划是JSON数组，每项包含：

```json
[{"name":"read_a","url":"https://目标站点/实际页面","task":"明确读取目标",
  "readonly":true,"reads":["对象A"],"scope":"站点与账号"},
 {"name":"draft_a","url":"https://目标站点/实际帖子","task":"填写指定草稿，禁止发送",
  "deps":["read_a"],"readonly":false,"writes":["帖子A草稿"],"scope":"站点与账号",
  "draft":{"field_label":"实际编辑器可访问名称","text":"感谢分享与支持 😊"}}]
```

示例含占位URL和字段名，不能直接作为实际测试完成证据。省略readonly时按可能写入处理；写节点使用账号写锁覆盖读、改、确认。读取可并发，但与同账号写入互斥。只依赖verified节点，失败仅阻塞相关后继。节点输入为独立快照，结果串行合并；取消后的迟到结果丢弃，不承诺撤回已经在途的网站写入。

## 接管

`--control-file .local/control.json`读取`{"pause":true}`，停止新决策/派发并等待当前步骤，生成每节点checkpoint。看到检查点后再进行人工操作；改为false恢复，重新观察并使旧证据失效。暂停仍计入绝对截止，不自动续租。检查点用于审计与进程内恢复，当前不支持进程重启后自动续跑。

`--storage-state`只加载用户明确提供的本机登录文件；应置于.local，不提交。BrowserSession API要求每会话独立Runtime/BrowserContext；受保护任务必须用create_context()禁用ServiceWorker，不能与普通写会话共用路由。

## 草稿与限制

DraftSpec精确检查当前输入框值；截图后清空并Escape取消，明确读到清空才记录取消成功；隐藏或消失不能单独证明清空。禁止可能提交的动作、危险按键和自动提交控件，并在Context级拦截网络写入。发生异常或Incomplete也尝试取消草稿。该保护可能阻断网站使用POST实现的读取接口；计划可用`read_post_urls`登记已逐项审计的精确读取地址，禁止查询参数、编码路径及已知发布端点，不能静默放宽其他写权限。该规则不能替代对未知接口业务语义的审核。

站点429遵循Retry-After或配置退避，共享站点限流器。所有浏览器I/O保留在创建线程；调度器使用隔离浏览器页面工作单元，模型默认串行。取消/截止采用协作检查：自定义工厂/节点必须遵守context.check和超时；无法强制终止不合作的Python回调。

本地脚本、真实模型、实际网站与官方成绩分开记录。当前129项回归通过，实际API+Edge的5节点受控闭环通过；小红书20帖尚为0/20，用户普通浏览器可访问，但独立自动化会话受限且尚未接管既有标签页，不能用受控站结果代替。完整证据见根目录M3交付说明。
